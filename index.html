Connections

交叉联系 · 四条汇流线

方向之间的联系比方向本身更值得看——过去两年的多数突破发生在这些交界处。

① 重建先验进入 SLAM

DUSt3R → MASt3R → MASt3R-SLAM / CUT3R

几何基础模型的两视图重建先验，替代了手工特征、标定与人工调参：MASt3R-SLAM 证明"基础模型先验 + 轻量对齐"即可构成免标定、可回环的实时稠密 SLAM。这是 2024–2025 年 SLAM 最重要的范式转移。

② 显式表示回灌 SLAM

3DGS → SplaTAM / MonoGS / Point-SLAM

高斯原语成为地图本身，可微光栅化成为跟踪的损失函数——从 NICE-SLAM 的神经隐式网格到"高斯即地图"，稠密 SLAM 的表示之争由 3DGS 接棒，渲染质量与几何精度同时提升。

③ 几何先验 ⇄ 生成先验

VGGT / π³ / MapAnything ⇄ Cosmos / Genie 3

世界模型要输出 3D 一致的视频，前馈几何模型要扩展到生成式的开放世界——两条路线正在"物理 AI"上汇合：一边为另一边提供几何监督与评测底座，另一边提供想象与补全的先验。

④ 从想象中学习，到现实里执行

World Models → DreamerV3 → DayDreamer → NWM / V-JEPA 2-AC

"在学到的世界模型里训练与规划，在真实世界执行"：从 2018 年的"梦境训练"构想到四足机器人 1 小时学会走路（DayDreamer），再到视频世界模型里的零样本导航规划（NWM）——这条线已走完闭环。
